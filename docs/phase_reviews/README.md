# Phase development reviews

This directory is the running engineering and research journal for the
top-down momentum crash monitor.

One review is created or updated at the end of every development phase. The
review is part of that phase's acceptance criteria and must be written before
the project moves to the next phase.

Each review records:

1. the phase objective and implemented scope;
2. files created or modified;
3. code and data reused from the repository;
4. deterministic rules and important implementation decisions;
5. representative outputs;
6. targeted and regression test results;
7. empirical findings;
8. engineering and research lessons;
9. assumptions, limitations, and known failure modes;
10. consequences and open questions for the next phase.

The review should distinguish clearly between:

- observed results;
- implementation conventions;
- hypotheses that still require validation.

Current reviews:

- `phase_0_review.md`: repository audit and re-scope;
- `phase_1_review.md`: deterministic macro regime monitor;
- `phase_2_review.md`: S&P 500 proxy and monthly 12-2 momentum portfolio.
